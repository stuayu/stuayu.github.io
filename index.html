あむ stuayu

テレビを録って、 配って、見るための 道具をつくる。

Mirakurun、EPGStation、EDCB、KonomiTV など、自宅でテレビを録画して見るためのオープンソースソフトを改造したり、足りない部品を自作したりしています。

主な作品

「フォーク」は、ほかの人のプロジェクトを複製して手を加えたものです。

  1. チューナー BonCasRelay B-CAS / ACAS カードを 1 台の PC に挿しておき、家の中の別の PC からも使えるようにするサーバー。設定はブラウザーからでき、Linux、macOS、Windows で動きます。 自作 Rust スター 1 2026年10月に更新
  2. その他 docker-recisdb-epgstation-konomitv 録画に必要なソフト一式（recisdb-proxy、EPGStation、KonomiTV、EDCB、Amatsukaze）を、コマンド一つでまとめて立ち上げられるようにしたもの。家の中のスマートフォンや PC から予約と視聴ができます。 自作 Python 2026年10月に更新
  3. 録画 EPGStation 番組表から録画予約や視聴ができる録画ソフト EPGStation の改造版。シリーズ録画の管理を強化するなど、さまざまな改造を入れています。 フォーク TypeScript スター 14 2026年10月に更新
  4. 録画 youtube-live-archiver 登録した YouTube チャンネルを見張って、ライブ配信とアーカイブを自動で保存するアプリ。自宅のサーバーで動かします。 自作 Python 2026年10月に更新
  5. チューナー recisdb-proxy-rs 放送の暗号を解くライブラリ libaribb25 を、Rust から使いやすくしたもの。Linux のチューナーからも BonDriver からも放送を読み込めます。 フォーク Rust スター 6 2026年10月に更新
  6. 録画 EDCB-to-EPGStation EDCB で録画が終わったら、その番組を EPGStation の録画一覧にも登録するツール。 自作 Rust 2026年10月に更新
  7. チューナー BonDriver_mirakc TVTest から mirakc や Mirakurun のチューナーを使うための部品。暗号化された通信（HTTPS）にも対応しています。 フォーク C++ スター 7 2024年7月に更新
  8. チューナー Mirakurun 家の中のチューナーをまとめて管理して、録画ソフトや視聴ソフトに放送を配るサーバー。 フォーク JavaScript スター 19 2026年10月に更新

すべてのリポジトリ

公開している 30 本を用途ごとに分けて、新しく更新した順に並べています。自分で一から作ったものは 9 本です。

録画9

予約して録る、録ったあとを整える

  • youtube-live-archiver 登録した YouTube チャンネルを見張って、ライブ配信とアーカイブを自動で保存するアプリ。自宅のサーバーで動かします。
  • EPGStationフォーク 番組表から録画予約や視聴ができる録画ソフト EPGStation の改造版。シリーズ録画の管理を強化するなど、さまざまな改造を入れています。
  • EDCBフォーク Windows 向けの定番録画ソフト EDCB。xtne6f さん版に、少しだけ修正を加えています。
  • EDCB-to-EPGStation EDCB で録画が終わったら、その番組を EPGStation の録画一覧にも登録するツール。
  • EDCB_Material_WebUIフォーク EDCB をブラウザーから操作する画面を、見やすいデザインにしたもの。予約、番組表、外出先からの視聴に対応しています。
  • tsdumpフォーク 全チャンネルを常に録画しておく、いわゆる「全録」を PC で行うための、シンプルで安定した録画ツール。
  • EPGS-to-Discordフォーク EPGStation の録画情報を Discord のチャンネルに投稿します。
  • FFmpeg-Buildsフォーク 動画の変換に使う定番ツール FFmpeg を、Windows と Linux 向けにビルドしたもの。
  • join_logo_scp_trialフォーク 録画した番組から CM を自動でカットする仕組み（join_logo_scp）を試すための環境。

チューナー11

放送を受けて、ほかのソフトに渡す

  • recisdb-proxy-rsフォーク 放送の暗号を解くライブラリ libaribb25 を、Rust から使いやすくしたもの。Linux のチューナーからも BonDriver からも放送を読み込めます。
  • BonCasRelay B-CAS / ACAS カードを 1 台の PC に挿しておき、家の中の別の PC からも使えるようにするサーバー。設定はブラウザーからでき、Linux、macOS、Windows で動きます。
  • Mirakurunフォーク 家の中のチューナーをまとめて管理して、録画ソフトや視聴ソフトに放送を配るサーバー。
  • BonCasClientフォーク BonCasRelay などのカード共有サーバーにつなぐための部品（DLL）。元のリポジトリの写しです。
  • px4_drvフォーク PLEX PX4/PX5/PX-MLT などのテレビチューナーを、Linux や Windows で動かすための非公式ドライバー。
  • dantto4kフォーク 新 4K8K 衛星放送の形式（MMT/TLV）を、一般的な録画ファイルの形式（MPEG-2 TS）に変換するツール。
  • BonDriver_BDAフォーク BonDriver は、チューナーを TVTest などのソフトから使うための部品です。これは多くの市販チューナーで使える汎用版。
  • BonDriverProxyExフォーク BonDriverProxy に、空いているチューナーを自動で選ぶ機能を加えたもの。
  • BonDriver_mirakcフォーク TVTest から mirakc や Mirakurun のチューナーを使うための部品。暗号化された通信（HTTPS）にも対応しています。
  • BonDriverProxyEx_webhook_notify BonDriverProxyEx を今どの PC が使っているかを調べて、Discord に通知します。
  • BonDriverProxyフォーク チューナーを、別の PC からネットワーク越しに使えるようにするツール。

視聴4

テレビやスマホで見る

  • Komorebiフォーク Android TV や Fire TV でテレビ番組を見るためのアプリ。
  • KonomiTVフォーク テレビ放送や録画番組を、ブラウザーで快適に見られるソフト KonomiTV。
  • epcltvappフォーク Android TV や Fire TV から、EPGStation の番組を見るためのアプリ。
  • TVTestRPCフォーク TVTest で見ている番組名を、Discord のプロフィールに表示します。

その他6

まとめて動かす、ほかの道具

  • Noveltyフォーク 「小説家になろう」の作品を読むための、シンプルで速いリーダーアプリ。
  • docker-recisdb-epgstation-konomitv 録画に必要なソフト一式（recisdb-proxy、EPGStation、KonomiTV、EDCB、Amatsukaze）を、コマンド一つでまとめて立ち上げられるようにしたもの。家の中のスマートフォンや PC から予約と視聴ができます。

  • team1 授業のチーム開発でつくった出席管理システム。
  • rename ファイル名をまとめて変えるプログラム。

あむ @stuayu

自宅でテレビを録画して見る環境を組むのが好きです。使っているオープンソースソフトに手を入れるうちに、改造版と自作のツールが少しずつ増えていきました。

チューナーの制御、B-CAS カードの共有、録画の管理、テレビ以外の端末で見る仕組みまで、放送を受けてから見るまでの流れを一通り触っています。最近は、それらをコマンド一つでまとめて立ち上げられるようにしています。
